## 执行纪律（三铁律 + git 唯一写者）
1. **Plan 先行**：动手前先读「必读」+ 目标文件，输出改动清单（改了哪些文件、每处什么改动），再开始实现
2. **测试先行（TDD）**：先写/更新测试并确认失败，再实现，直到测试通过
3. **小步报告**：完成一个逻辑单元就报告，不攒到最后
4. **不 commit**：git 唯一写者 = Hermes 主控（主控验证全绿后统一 commit）；dsh 完成即报告，禁止 git commit
